# 个人开发版构建与手机验收

目标固定为 iPhone 13 Pro / iOS 26.5.2（23F84）/ 无 Apple Developer Program 付费会员 / LiveContainer + LocalDevVPN。本轮仅操作专用 iOS 26.2 模拟器，所有实际手机测试由用户完成。构建成功不代表 26.5.2 的设备协议、容器权限或后台执行已通过。

## 构建和产物

在任务独立工作区执行：

```sh
zsh scripts/test-feature-data.sh
zsh scripts/test-app-model.sh
zsh scripts/test-movement.sh
zsh scripts/test-updates.sh
zsh scripts/test-localization.sh
python3 scripts/validate-localizations.py
zsh scripts/package-personal-build.sh
```

模拟器UI可用 `zsh scripts/test-ui-simulator.sh <模拟器UDID>` 重现（需要XcodeGen）。此命令只接受现有模拟器UDID，不会操作物理手机。

需要 Xcode 26.2（本轮实用版本）及匹配命令行工具。仓库已包含本轮从 Rust 源码重新构建的设备和 Simulator arm64 静态库，通常不必再次编译 Rust。若修改原生代码，按 `scripts/build-pairing-engine.sh` 帮助重建，保留旧框架后再替换，不只改 Swift 头文件。

构包脚本生成未签名 Release archive，写入构包时的 UTC 时间，将 IPA 和 JSON 清单放在 `outputs/`，文件名使用 America/Los_Angeles 可读时间。清单包含 IPA/主程序 SHA-256、源文件摘要、版本、系统下限和实际未提交状态。验证包括设备平台与最低系统、独立 Bundle ID/回调、可执行权限、ZIP CRC、十语言及权限资源、空统计配置和无隧道扩展。没有安装、签名、提交或发布步骤。

设备包显示 `Roam Control Dev`，版本 `0.9.9`、Build `31`，最低声明 `iOS 26.0`，回调 `roamcontrol-pandy`。这些是本 fork 的元数据；官方参考是 0.9.9 Build 105，不能把两个 Build 当成同一发布线。

## 建议手机验收顺序

保留现有可用的 wloc。把新 IPA 作为单独客体导入 LiveContainer，按原来已验证的流程在首次启动前打开“修复本地通知”。不要将已有 wloc 的数据目录或配对秘密复制给开发者；普通备份明确不包含配对文件。每轮只运行一个位置会话。

| 顺序 | 操作 | 记录什么 |
|---|---|---|
| 1 启动与身份 | 导入新客体，核对名称、Build 31；退出重开；中文/英文切换 | 无崩溃、未覆盖 wloc、偏好持久化；LiveContainer 版本 |
| 2 配对和外部 VPN | 手动开启 LocalDevVPN，导入原有效 RPPairing，运行连接检查，再重开 | 导入/Keychain/连接是否成功；无效文件不覆盖原记录；不反馈文件和密钥 |
| 3 固定位置 | 选公开点 A 开始，外部地图确认，再换 B，停止并恢复 | UI、外部地图实际位置分开记录；“设备确认清除”后真实 GPS 仍可能需要重新取得 |
| 4 清除失败与取消 | 短路线中断 VPN，再停止；重连后恢复；连接准备期间取消后立即重试 | 未确认清除时保留恢复入口；取消后没有迟到定位；手工确认真实位置已回来后可以正常继续 |
| 5 路线模式 | Walking/Cycling/Driving 各一条短路线；改速度、暂停继续、返回/改向 | 速度单位、实际推进、剩余距离/估时；路线服务不支持时的错误和手绘替代 |
| 6 点绘与手绘 | 已选终点时加途经点；撤销/清空；一指绘制、双指移动；折叠展开 | 起终点不丢、无跨段误连；暂停/停止入口始终可达 |
| 7 GPX | 文件选择器和 Files“用此应用打开”分别导入；导出再导入；取消、无效 XML、分段轨迹 | 有效几何一致，坏文件不替换当前路线，活动会话中不强行切换轨迹 |
| 8 摇杆 | 轻推、满推、松手、暂停/继续、停止恢复；摇杆转路线 | 松手停止推进；历史不会被每个采样点填满；恢复位置正确 |
| 9 中断恢复 | 活动中切后台、锁屏、断 VPN、终止客体后重开；Wi-Fi 和蜂窝分别测 | 各自持续时间、是否前台降级、暂停/路线进度是否保存；不预设无限后台 |
| 10 坐标兼容 | 北京等公开点，分别使用地图点、手输 WGS84、GPX；测试 Off/Automatic/Force 及跨来源改向 | 地图显示与最终设备坐标分别核对；手输/GPX 在自动模式不变；其他地区不偏移 |
| 11 备份 | 收藏重命名/排序、历史和偏好导出；新客体预览并恢复；有效 A 后选择损坏 B | B 不残留 A 的确认按钮；配对/会话/统计身份不迁移；仅承诺本 fork 格式 |
| 12 设置与隐私 | 查看诊断预览，默认不含地点；尝试手动更新；大字体/深色/RTL | 分享内容和提示正确；更新只查本 fork，不自动下载；地图网络和统计开关分开理解 |

需要反馈的最小记录：包文件名/哈希、系统与容器版本、网络类型、测试编号、操作、UI结果、外部地图结果，以及不含秘密的错误文案。可选诊断应先预览，不自动上传。

## 已知等价范围

运动算法是公开行为的独立实现，转弯停顿来自路线几何，不使用交通灯实时数据。ETA 是目标速度与计划停顿的估算。系统时区由 iOS 自己处理，本 fork 未增加未公开的系统时区写入接口；请将时区变化与恢复作为手机回归项。

官方新版源码和专有备份格式未公开，因此不承诺算法逐位一致、像素完全一致或导入官方/wloc备份。地图搜索/反查使用 Apple MapKit；没有默认加入 wloc 的第三方 Worker 搜索、国家安装计数、诊断上传或新的统计服务。默认关闭统计且构包配置为空；这不表示地图和用户启用的更新检查没有网络请求。

新增手机回归项：

| 编号 | 操作 | 应观察的结果 |
|---|---|---|
| A01 原生协议 | 固定A→更新B→停止；再做清除失败后恢复 | set/update/clear能完成；仅协议确认时显示设备确认清除；外部地图的真实GPS恢复单独确认 |
| A02 外部停留 | 跳入LocalDevVPN后停留至少40秒再手动返回；蜂窝设置页同样停留 | 返回后继续发现，不因在别的App停留而立即超时 |
| A03 活动重连 | 路线推进中关闭再打开LocalDevVPN，恢复成功后重复至少3次，保持Roam Control可执行 | 有限自动重连、暂停推进；恢复后保留位置/进度/原暂停状态。点击取消后只清除，不能迟到开始新位置 |
| A04 保留连接选新点 | 短路线到达或摇杆暂停→New Location→选B→Update | 连接保持，不先恢复真实位置；历史首项是路线目的地而非起点 |
| A05 失败后排障 | 制造无写入的发现失败→移除配对或重置 | 可以操作；如果存在未确认清除，说明原因并保留清除所需配对 |
| A06 准备与系统到期 | 移动数据引导中取消；实际系统后台到期后返回 | 准备圈退出；系统到期有原因，设备确认清除与保留路线重新开始分开 |
| A07 配对通知 | LiveContainer启用原安装指南的Fix Local Notifications；准备页后切设置配对 | PIN/阶段超时提示能回到正确客体；停留设置等待到期并观察通知；记录后台执行模式。导入成功/失败后临时副本应清理；拒绝通知不阻止导入已有文件 |
| A08 GPX与兼容 | Force导出再导入，切换Walking/Cycling/Driving；活动时查看兼容选项 | 无重复转换；换模式不丢坐标来源；活动会话不能改变坐标兼容模式 |
| A09 交互 | Stop取消/确认；复制地址；检查预计到达、摇杆暂停继续、跟随缩放 | 取消停止不丢进度；内容和单位正确；预览/暂停跨分钟时预计到达刷新；地图动画仅影响显示 |
