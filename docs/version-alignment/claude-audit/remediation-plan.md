## 契约

- 设备clear确认与用户手动确认继续分开；自动重连不能丢弃未确认清除的责任；显式停止不得再次set。
- 会话兼容模式在首次开始时固定，并写入恢复记录；同一会话切位置/路线/摇杆沿用。显示和标准GPX使用明确坐标空间，转换只在设备边界执行。
- AppModel广播设备状态到MovementController；运动开始/取消/重连不再依赖SwiftUI页面是否更新。视图观察只更新界面。
- New Location只释放运动控制器，把恢复记录转为当前固定位置，保留原生活动会话。
- 普通failed且无worker/未清除责任/恢复记录时允许移除配对和重置；其它情况显示针对操作的错误。
- 无效运动子快照降级为已保存的固定位置恢复，不因路线格式校验失败隐藏清除入口。
- 地图插值仅作用于呈现，不写入设备、历史或恢复记录。
